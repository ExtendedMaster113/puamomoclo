# Momoiro Clover Z Symbols Supplement and Extended-A

**Creator:** Stardust Promotion
<br>
**Source:** Under-ConScript Unicode Registry (UCSUR)

## Overview

This proposal documents two supplementary private-use blocks for Momoiro Clover Z symbols, complementing the existing Momoiro Clover Z Symbols block at U+F3700–U+F371F.

- **Momoiro Clover Z Symbols (U+F3700–U+F371F):** ???
- **Momoiro Clover Z Symbols Supplement (U+F3720–U+F37FF):** Former logos, additional branding, icons, member symbols, former-member symbols, and miscellaneous group-related artwork.
- **Momoiro Clover Z Symbols Extended-A (U+F3BE0–U+F3BFF):** Alternative logos, release-collection branding, watermarks, icons, ticket branding, and Angel Eyes fan-club branding.

The historical Momoiro Clover logo is retained as a distinct historical identity. Existing character assignments are preserved, and new assignments should be checked against the source mapping to avoid duplicates.

All character names and mappings in this proposal are subject to verification against the original reference and the applicable UCSUR conventions.
